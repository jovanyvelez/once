  • ¿Y si quieres encontrar la edad más alta? Un caos de if anidados.

Arreglo = estructura homogénea
Un arreglo es una colección de datos del mismo tipo almacenados en posiciones contiguas de memoria. Un solo nombre (por ejemplo edades) y múltiples casillas numeradas (índices).

Comparación directa en C#

❌ Caos de variables
int edad1 = 25;
int edad2 = 32;
int edad3 = 18;
int edad4 = 45;
int edad5 = 27;
// ... ¡y así 50 veces!

// ¿Promedio?
double prom = (edad1 + edad2 + edad3 +
               edad4 + edad5 + ... ) / 50;
✓ Arreglo elegante
int[] edades = { 25, 32, 18, 45, 27,
                 31, 22, 38, 29, 41 };

// ¿Promedio? Un bucle.
double suma = 0;
for (int i = 0; i < edades.Length; i++)
    suma += edades[i];
double prom = suma / edades.Length;
🎯
Mini-reto mental
Si tuvieras que guardar 1,000 edades con variables sueltas, ¿cuántas líneas de código escribirías? ¿Y con un arreglo? Respuesta: ~1,000 líneas vs 1 línea de declaración. Esa es la potencia de los arreglos.
02

Anatomía del Arreglo y el Poder del Cero

// Declaración, índices y acceso directo
45 MIN125 XP
Un arreglo necesita tres cosas: un tipo de dato, un nombre, y un tamaño. Y lo más raro: la primera posición es el 0, no el 1. Hoy entenderás por qué.

Declaración en C#: 3 formas

Forma 1 · Solo declarar
// Creas el arreglo, todo en 0 por defecto
int[] edades = new int[5];

// edades[0] = 0, edades[1] = 0, ...
Forma 2 · Inicializar al declarar
// Valores al momento de crear
int[] edades = { 25, 32, 18, 45, 27 };

// El tamaño se infiere: 5 elementos
Forma 3 · Combinada (explícita)
int[] edades = new int[] { 25, 32, 18, 45, 27 };
string[] nombres = new string[3] { "Ana", "Luis", "María" };

El Poder del Cero: ¿Por qué contamos desde 0?

En la memoria RAM, un arreglo es un bloque contiguo de celdas. El nombre del arreglo (ej: edades) en realidad es la dirección de memoria de la primera celda.

Cuando escribes edades[3], la computadora calcula:

dirección_final = dirección_base + (índice × tamaño_elemento)

edades[3] = dirección_base + (3 × 4 bytes)   // int ocupa 4 bytes

Si empezamos desde 0, el cálculo es directo y eficiente: edades[0] = dirección base + 0 = la misma base. No necesitamos restar 1 cada vez.

⚠
Regla de oro
Si un arreglo tiene N elementos, los índices van de 0 a N-1. El último elemento siempre está en arreglo[arreglo.Length - 1].

Tienes los valores [42, 18, 27, 35, 19]. El orden correcto es: edades[0]=42, edades[1]=18, etc. Arrastra cada ficha a su casilla.

Arreglos paralelos: el patrón del ciudadano

Cuando tienes múltiples arreglos del mismo tamaño y usas el mismo índice para acceder a datos relacionados, estás usando el patrón de arreglos paralelos. Es el patrón clásico antes de aprender POO.

Código completo del simulador
using System;

class CiudadDigital
{
    static void Main()
    {
        // Tres arreglos PARALELOS
        string[] nombres       = { "Ana Ruiz", "Luis Torres",
                                 "María Vega", "Pedro Soto",
                                 "Sofía Lima" };
        int[]    edades         = { 28, 35, 22, 41, 29 };
        double[] calificaciones = { 8.5, 9.2, 7.8, 6.5, 9.8 };

        // Acceder al ciudadano #2 (índice 2)
        int i = 2;
        Console.WriteLine($"Nombre:  {nombres[i]}");
        Console.WriteLine($"Edad:    {edades[i]}");
        Console.WriteLine($"Calif:   {calificaciones[i]:F1}");
    }
}
⚠
Pro-Tip: Arreglos paralelos son un antipatrón
Aunque funcionan, los arreglos paralelos son frágiles: si eliminas un elemento de nombres pero no de edades, los índices dejan de coincidir. La solución profesional es usar una clase (class Ciudadano) con POO. Lo aprenderás en el próximo módulo.
04

El Taller de Procesamiento Masivo

// Recorrer arreglos con for y calcular estadísticas
60 MIN150 XP
El verdadero poder de los arreglos se libera cuando los recorres con un ciclo. Un for puede visitar cada casilla y procesarla: sumar, contar, buscar, comparar. Esto es la base del análisis de datos.

El patrón universal: recorrer con for

Patrón clásico
for (int i = 0; i < arreglo.Length; i++)
{
    // Procesa arreglo[i]
    Console.WriteLine(arreglo[i]);
}
Patrón moderno: foreach
foreach (var elemento in arreglo)
{
    // No necesitas índice
    Console.WriteLine(elemento);
}

💻 El código completo en C#

Calificaciones.cs
using System;

class AnalisisCalificaciones
{
    static void Main()
    {
        const int TOTAL = 5;
        double[] notas = new double[TOTAL];

        // LLENAR EL ARREGLO
        for (int i = 0; i < TOTAL; i++)
        {
            Console.Write($"Nota #{i + 1}: ");
            notas[i] = double.Parse(Console.ReadLine());
        }

        // CALCULAR ESTADÍSTICAS
        double suma = 0;
        double mayor = notas[0];
        double menor = notas[0];

        for (int i = 0; i < TOTAL; i++)
        {
            suma += notas[i];
            if (notas[i] > mayor) mayor = notas[i];
            if (notas[i] < menor) menor = notas[i];
        }

        double promedio = suma / TOTAL;

        // MOSTRAR RESULTADOS
        Console.WriteLine($"\nPromedio: {promedio:F2}");
        Console.WriteLine($"Más alta: {mayor:F2}");
        Console.WriteLine($"Más baja: {menor:F2}");
        Console.WriteLine(promedio >= 6 ? "✅ Aprobado" : "❌ Reprobado");
    }
}

Nunca uses int max = 0 cuando los valores pueden ser negativos, o int max = 1000000 sin razón. Siempre inicializa con arr[0], el primer elemento real del arreglo.
